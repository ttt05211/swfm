## 三条方向

### 1. Memory importance 温度

当前 Memory 融合权重为 `exp(clamp(score,-8,8))*coverage*age`。保留特征与几何，把 learned score 以固定 T=2 降温，或 score=0（均匀 learned importance）；static/dynamic 共用变化，原 coverage 和 age 保留，分子与分母共同变化。T=1 恒等由真实小网格测试验证。这不同于此前失败的 Memory 整体幅度缩放：此次改变证据之间的相对权重，不压低最终特征。

两种候选均报告不加和加固定 FREE−1；不搜索温度，不重训。实际真实64窗运行约95秒。相对 FREE−1 原参照18.386991/29.104434：T2＋FREE−1为18.358981/29.068134，−.028011/−.036299；均匀＋FREE−1为18.274127/28.911557，−.112864/−.192876。后32也下降，不采用，不继续扫温度。

### 2. 固定二元占据范围，只校准语义类别

占据门固定为 `max(Z[:17]) >= Z[17]-1`。仅在占据门内，把类别改为 `argmax(Z[:17]+b)`，b为17个所有位置/时距共享的自动拟合偏置。没有手工指定类别、空间区域、距离、速度或时距规则，也没有新增特征网络。

二元门不受b影响，因此这一条的 binary IoU **逐体素严格等于 FREE−1 参照**；只能改善/损坏语义排序，不制造额外占据。额外17个标量在前32未来GT上拟合，属于**有标签目标域输出校准**，不是无标签或zero-adaptation。

使用固定两个目标：CE 与 soft-IoU；每个只优化17个居中偏置，Adam lr.05 / L2 .01 / 固定200步最终值，不按后32挑best-step。前32每类/时距/窗最多128点分层抽样，带`原体素数/抽样数`权重还原体素统计；soft-IoU保留假阳性free与不可改正的漏占据惩罚。原网络冻结。参数文件在读取后32未来标签前完成并保存。

思路参考[Guo等，ICML2017 的输出logit校准](https://proceedings.mlr.press/v70/guo17a.html)：这是其偏置项思想的受限变体，另外固定二元门，并非直接复现完整vector scaling。单一temperature不改变argmax，不能指望仅靠所有输出统一除以T来改变这些硬分类指标。

实际真实32窗拟合＋64窗评估共约111.5秒，含两个偏置臂各200步。后32：FREE−1参照18.277093/29.125272；CE校准18.142322/29.125272（mIoU−.134770）；soft-IoU校准18.223464/29.125272（mIoU−.053629）。前32选出的soft-IoU在拟合人口仅+.008773m；全64描述性成绩18.391614/29.104273，较参照+.004699m，但后32为负，**不能用这个全64微涨掩盖迁移失败**。两臂不采用，不延长步数/再扫正则或lr。

### 3. 历史静态概率融合

仅将TransportPrior的t0静态one-hot换成四历史STC经已知历史ego对齐后的概率均值，使用已有age0.5权重；类别动态/静态划分与原TransportPrior一致。除有效支持/出界处理外，没有硬票数、类别特定阈值、空间白名单、膨胀/腐蚀或GT补洞。动态source身份、形状、WM运动、Strong/CLEAR与Memory保留，新的概率prior送入同一冻结U-Net。

这不同于此前失败的编码前temporal embedding/硬多数投票：此次只在TransportPrior概率接口做一次连续融合。只固定这一个候选，同时报告原读出与FREE−1读出，不扫融合强度。

实际真实64窗约76.6秒。全64 FREE−1参照18.386962/29.104360，新候选18.236503/28.919393（−.150460/−.184967）；后32也下降。不采用，不继续加票数/融合率/类别门限救分。
