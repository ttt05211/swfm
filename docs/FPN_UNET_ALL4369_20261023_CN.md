# 冻结完整两轮 FPN＋U-Net：OCC 原版 / STC 固定历史衰减，全集评估

用户批准用固定历史衰减跑全集。不使用失败的 norm320 适配，也不重训或重建 learned bank。只读原完整 TRAIN20430×2 最终 `epoch_0002.pt`，2,520,442 参数；当前源64窗原版 OCC Refiner 为50.866113 mIoU /63.829317 IoU，STC age 为18.283820/28.621200，**这些不是全集分数，也不能证明所有旧版本在同一全集上都更差**。

## 评估条件

- OCC：原模型、原历史 Memory 融合。STC：仅 Memory 使用固定0.5秒半衰期，真实四历史时间戳，nominal权重[1/8,1/4,1/2,1]。分子分母一起加权，原输入不原地修改。
- 两路 Encoder/WM/KTA/Strong/CLEAR/Transport Prior 均不改；每窗只运行一次 FPN、WM、Memory、U-Net，不额外计算无衰减 STC Refiner 作新对照。
- GT future ego 同时条件化 Query 和所有投影；不测内部或外部 Pred ego。四历史→六未来，报告1/2/3秒及平均 mIoU、IoU、MovingMicro，并保留JSON每类和MovingMacro。
- 固定完整 VAL4369 /150场景，两种输入使用同一人口。不沿用旧planner裁剪4219，不跳过STC缺文件；预检缺文件直接报错。
- 原64为前缀，其余4305按key排序，单独保留分组结果；先累加整数 confusion，再算全集，不能平均两组分数。OCC/STC都用dense-valid，不读取输入camera/lidar mask，评分为full-grid。所有六帧预测后再读未来GT/Moving。
- 全集主表4行：occ_gt_transport / occ_gt_semantic_refine / stc_gt_age_transport / stc_gt_age_semantic_refine。STC Transport本身不受Memory衰减影响，标记age是为了声明整套配置。
- 原 checkpoint、Adam、缓存不写入；独立输出快照与source SHA/实现/数据身份，完整窗保存与恢复。不做阈值搜索、额外适配、重训、模型选择或FPS测试。运行时间不是推理FPS。

## 后台启动

```bash
cd /root/nas/occ/swfm
git switch feature/shared-history-execution-speed-v2
git pull --ff-only https://ghfast.top/https://github.com/ttt05211/swfm.git feature/shared-history-execution-speed-v2
conda activate OccFM
export FPN_UNET_ALL_GPU=0
export FPN_UNET_ALL_RESUME=0
export FPN_UNET_ALL_DIR="$PWD/outputs/p0_f9_shared_history/fpn_unet_all4369_$(date +%Y%m%d_%H%M%S)"
nohup bash tools/fpn_unet_all/run.sh > "$FPN_UNET_ALL_DIR.log" 2>&1 &
echo "PID=$!  DIR=$FPN_UNET_ALL_DIR  LOG=$FPN_UNET_ALL_DIR.log"
tail -f "$FPN_UNET_ALL_DIR.log"
```

只从唯一完成的 `fpn_unet_full_2ep_*` 目录加载。多个完成目录时设置 `FPN_UNET_FULL_DIR=实际原完整两轮训练目录`；不按mtime或得分自动挑选。后台启动前确认所选GPU没有竞争任务，脚本不会停止其他进程。`tail -f` 按Ctrl-C只退出日志查看，不停止后台评估。

输出：`summary.txt`、`evaluation.json`、`progress.json`、`occ/stc_original64_state.json`和`occ/stc_remaining4305_state.json`、冻结来源快照。进度每8个完整窗落盘；正常中断在完整窗退出并保存。

