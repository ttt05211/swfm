## 2. Why V19 exists

The completed 3--6 s zero-shot rollout exposed a scene-state maintenance
limitation.

Formal open-loop 4/5/6 s mIoU:
28.835 / 25.412 / 22.945.

Teacher-forced GT-history 4/5/6 s mIoU:
51.490 / 41.711 / 35.965.

Thus the frozen relative-horizon predictor still works from a clean scene
state; the long-range limitation is maintaining a valid state without new
observations.

The method story is:

Remember what has been observed
-> transport content with a reliable ancestor
-> generate only content without a reliable ancestor
-> promote stable generated content back into memory.

## 3. V19 method contract

### 3.1 Dynamic source path

Current or re-detected sources remain authoritative and use the exact frozen
Clean-E14 path.

SourceMemory stores lifecycle information:
identity, class, canonical geometry, historical centres, velocity, confidence,
provenance and age since real observation.

Memory does not replace detection.

At a block boundary:

    generated/current occupancy
      -> Strong redetection
      -> SourceMemory reconciliation
           matched detected     -> exact V18
           new detected         -> exact V18 + fresh memory identity
           unmatched memory     -> low-confidence add-only recovery

### 3.2 Static memory

Only Occ3D mask_lidar-observed non-motion-capable geometry is remembered.

Rules:

- dynamic observations never enter static memory;
- dynamic occlusion does not erase static memory;
- newer genuinely observed free evidence clears stale static occupancy;
- newer valid static observation wins;
- future rendering is deterministic world-to-future-ego geometry;
- composition is add-only.

### 3.3 Innovation

Innovation is not "whatever V18 gets wrong".

It is future occupancy with no reliable historical ancestor, principally:

- future-born dynamic content;
- never-seen static content;
- source shape innovation.

History is explicitly warped into each future ego frame before the innovation
network. Deterministic ego geometry is not learned.

## 5. Important implementation invariants

1. Current/re-detected source order is the original Strong order.
2. Matched sources are never rewritten by memory.
3. Memory-only recovery runs separately and composes only into free voxels.
4. Source state separates:
   - detected_at_anchor;
   - age_since_real_observation.
5. Memory adapters are gate-isolated from detected sources.
6. New memory heads are zero initialized.
7. Static memory uses mask_lidar, not semantics!=free as visibility.
8. Innovation is protected add-only.
9. Future GT is diagnostic/training supervision only, never prediction input.
10. Stable track IDs survive reconciliation and can be reused in later blocks.

## 7. Current source reconciliation implementation

- deterministic same-class nearest one-to-one reconciliation;
- memory age/confidence gating;
- stable track-ID assignment;
- unmatched-memory selection only.

Default diagnostic settings:

- max centre distance: 4.0 m
- max memory age: 6.0 s
- confidence decay tau: 3.0 s
- minimum memory confidence: 0.15

- v18_redetect_baseline

- reconciled_memory_static

source and separately forecasts only unmatched memory sources with frozen V18.
